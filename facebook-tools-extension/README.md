# Facebook Chat Tools Extension

إضافة لمتصفح Chromium/Chrome توفر خيارين داخل فيسبوك أو ماسنجر:

1. **إرسال رسالة محددة** إلى المحادثة المفتوحة.
2. **حذف المحادثات الظاهرة حاليًا** بشكل متتابع.

## ملاحظات مهمة

- الإضافة تعمل فقط عندما يكون حسابك مفتوحًا ومُسجّل الدخول.
- الحذف يعتمد على واجهة فيسبوك الحالية وقد يحتاج تحديثًا إذا تغيّرت الواجهة.
- عملية الحذف غير قابلة للتراجع.

## طريقة التثبيت

1. افتح: `chrome://extensions`
2. فعّل **Developer mode**.
3. اضغط **Load unpacked**.
4. اختر مجلد `facebook-tools-extension`.

## الاستخدام

1. افتح `facebook.com/messages` أو `messenger.com`.
2. افتح محادثة إذا أردت الإرسال.
3. اضغط أيقونة الإضافة:
   - اكتب الرسالة واضغط **إرسال إلى المحادثة المفتوحة**.
   - أو اضغط **حذف كل المحادثات (الظاهرة حاليًا)**.
